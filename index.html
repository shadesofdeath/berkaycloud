How every app is built

No runtime

Statically linked. Nothing to install first, nothing to update later. It runs on a fresh Windows.

No installer

One .exe you can drop anywhere. When an installer exists it is optional, and it never asks for admin.

No telemetry

No analytics, no crash reporters, no update pings. If it talks to the network, you turned that on.

Reversible

Every write is recorded. Anything an app of mine changes, it can put back exactly as it found it.
