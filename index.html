01 About

Software that respects the machine it runs on.

I'm Berkay Ay, ShadesOfDeath on the internet. I write native Windows software: the kind that ships as one executable, starts instantly and asks for nothing.

I care about what happens beneath the window: registry writes that can be undone, pixels that are read instead of guessed, a tray icon that stays quiet until it has something to say. Most of it is pure Win32 and C++20 with Direct2D on top; some of it is C# and WPF when a ribbon or a settings page needs to feel like Windows 11.

Everything is open source and free. If an app of mine is on your machine, it is because you put it there — and you can read every line of what it does.

02 Rules

Four rules, no exceptions.

01

No runtime

Statically linked. Nothing to install first, nothing to update later. It runs on a fresh Windows.

02

No installer

One .exe you can drop anywhere. When an installer exists it is optional, and it never asks for admin.

03

No telemetry

No analytics, no crash reporters, no update pings. If it talks to the network, you turned that on.

04

Reversible

Every write is recorded. Anything an app of mine changes, it can put back exactly as it found it.
